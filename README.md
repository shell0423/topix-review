# TOPIX継続基準チェック — 次期TOPIX除外候補ウォッチ

**閲覧はこちら → https://shell0423.github.io/topix-review/**

2026年10月の次期TOPIX初回定期入替(判定基準日: 2026年8月最終営業日)に向けて、
現行TOPIX構成銘柄のうち**継続基準を満たさない「除外候補」**を毎営業日リストアップしています。

- 判定①: 浮動株時価総額(終値 × 発行済株式数 × 浮動株比率) ≤ 410億円
- 判定②: 年間売買代金回転率 < 0.14(JPXの継続基準)
- 参考として累積97%/96%ボーダーも全上場ベースで毎日自前計算

ページ内の「使い方」「用語解説」「経緯」タブに、計算方法・出典(JPX公表資料)・
制度の背景をまとめています。
