TOPIX継続基準チェック — 除外候補リスト

列見出しクリックでソート / 黄下線=閾値±20億円のボーダー付近

このアプリは何をするか

2026年10月の次期TOPIX初回定期入替(判定基準日: 2026年8月最終営業日)に先駆けて、 現行TOPIX構成銘柄のうち継続基準を満たさない「除外候補」を毎営業日リストアップします。 判定は次の2条件で、どちらかに該当すると除外候補です。

  • ① 浮動株時価総額 ≤ 億円(累積97%ボーダーの実測値に余裕を持たせた設定値)
  • ② 年間売買代金回転率 < (JPXの継続基準そのまま)

日々の使い方

  • ダブルクリックで開く: TOPIX判定を開く.command をダブルクリック → 最新データで再計算してこのページが開く(約2秒)。site/index.html を直接開けば再計算なしで前回結果を表示
  • 自動実行: 平日21:00に自動で再計算(warehouseの株価更新が18:30のため)。Macがその時刻に起動していなければ翌営業日に自然回復
  • 判定リストの見方: 赤い行=除外候補、グレー=データ欠損。黄色い下線=閾値±20億円のボーダー付近で、日々の株価で出入りしうる要注目ゾーン。検索ボックス・判定フィルタ・列見出しクリックのソートで絞り込み
  • Excelで見る: data/results/result_日付.csv をダブルクリック(日次で蓄積)
  • Discord通知: .env に Discord の Webhook URL を設定すると、日次サマリと前日比の新規該当/解消が届く(未設定なら通知なしで動作。キー名は .env.example 参照)
  • 閾値の変更: data/settings.json の ff_mktcap_oku(億円)を書き換えるだけ

注意(精度の留保)

  • 浮動株比率(FFW)は2026年3月31日時点の公表値。以後の見直し分はズレる
  • 発行済株式数は決算短信ベースの近似。期末後の増資・自己株消却は次の短信まで未反映
  • 備考に⚠️がある銘柄は元データに癖がある(詳細は用語解説タブ)。詳しい留保一覧は README.md 参照

浮動株時価総額 — 計算方法と参照元

本アプリの判定①で使う中心的な数値。「時価総額」といっても普通の時価総額(株価×発行済株式数)ではなく、 市場に流通しうる浮動株ベースで計算します。JPXの公式定義と、本アプリでの再現方法は次のとおりです。

浮動株時価総額 = 終値 × 発行済株式数(自己株込み) × 浮動株比率(FFW)
定義の出典(公式)
JPX総研「東証指数算出要領(TOPIX・見直し後)」— 浮動株時価総額 =「指数用上場株式数 × 浮動株比率 × 価格」。本アプリはこの定義を再現しています。
終値
warehouse(J-Quants)の当日終値(生値)。毎平日18:30更新のためその日の判定ができる。
発行済株式数(自己株込み)
決算短信サマリの期末発行済株式数で、JPXの「指数用上場株式数」を近似。 自己株式を引かないのは、自己株がFFW側の固定株として控除済みだから(二重控除になるため)。 決算期末より後の株式分割・併合は調整係数で株数を補正。
浮動株比率(FFW: Free Float Weight)
発行済株式のうち市場に流通しうる割合。FFW = 1 − 固定株比率で、自己株・親会社や役員の保有分・ 政策保有株などが固定株として除かれる(算定方法の公式資料: 「浮動株比率の算定方法(見直し後)」)。 実数値は、JPXが見直しページで例外的に無料公開している 「浮動株比率一覧(2026年3月31日時点)」CSV (全上場約3,700銘柄・0.05刻み)を使用。通常この個別データは有料(J-Quants DataCube)でしか手に入らない。
計算例(極洋 1301)
終値4,515円 × 12,078,283株 × FFW 0.65 ≈ 354億円 → 閾値以下なので除外候補。

年間売買代金回転率

「浮動株時価総額に対して、年間でどれだけ売買されたか」を表す流動性指標。判定②で使用。

月次回転率 = (日次売買代金の中央値 × 営業日数) ÷ 月末浮動株時価総額
年間回転率 = 直近12か月の月次回転率の合計
出典
上記「東証指数算出要領(TOPIX・見直し後)」および 「TOPIX等の見直しの概要」(2026年5月・JPX総研)p.3脚注。 上場1年未満の銘柄は上場月を除いて平均×12で年率換算(算出要領(4))。
本アプリでの再現
売買代金はwarehouseの実測値(2026年5月末以降)+それ以前は終値×出来高で近似(誤差は中央値0.4%程度)。 売買が無かった営業日はゼロとして中央値に含める保守的解釈を採用。

選定基準・判定に関する用語

継続基準(バッファ・ルール)
すでにTOPIX構成銘柄である銘柄が残るための基準: 年間回転率0.14以上 かつ 浮動株時価総額の累積比率が上位97%以内。 新規追加基準(0.2以上・96%以内)より緩く設定され、入替の頻発を防ぐ。
累積比率(上位97%/96%)
回転率条件を満たす銘柄を浮動株時価総額の大きい順に並べ、累積シェアが97%(継続)/96%(追加)に達するまでが「圏内」。 固定の金額基準ではないため毎日動く。本アプリはこのボーダーを全上場ベースで毎日自前計算して参考表示している (ヘッダーの「累積97%ボーダー ≈ ◯◯億円」)。閾値億円はこのボーダー実測値 (JPX試算では2026年3月末時点で約360億円)に余裕を持たせたユーザー設定値。
判定ステータス
除外候補=2条件のどちらかに該当 / 継続圏=両方クリア / データ欠損=FFW未収録(2026年3月末以降の新規上場)や株式数不明で計算不能。
ニューインデックス区分
TOPIX Core30・Large70・Mid400・Small 1・Small 2 のサイズ別区分(JPX構成銘柄一覧の区分をそのまま表示)。
移行措置銘柄
2026年10月の初回入替で継続採用されなかった銘柄。即時除外ではなく 2026年10月から四半期ごと8段階(87.5%→0%)でウエイトが低減され、2028年7月に完全除外。 2027年10月に再評価があり、継続基準を満たせば低減停止(=復帰)する。
TOPIX Next-tier
TOPIXに選定されない銘柄(移行措置銘柄含む)のうち一定の流動性(回転率0.1以上・累積99%以内)がある約800銘柄で 2026年10月末から算出開始される新指数。除外＝即無視ではない受け皿。
備考の⚠️マーク
元データ(warehouse)の既知の癖がある銘柄。「種類株混入」=2026年5月25日以前の株価データに 同一企業の種類株(例: ソフトバンクの社債型種類株)が混ざっていたため、回転率を2026年6月以降の実績から年率換算した推定値で代替。 「大幅断絶」=データ切替前後で売買代金が大きく飛んでおり回転率は参考値。

なぜこのアプリを作ったか

JPX総研「TOPIX等の見直しの概要」(2026年5月)で示された次期TOPIXへの移行スケジュールが出発点。 判定基準日が2026年8月最終営業日に迫っており、公式の選定結果公表(10月7日)を待たずに 「今の株価で判定したらどの銘柄が落ちるのか」を毎日先回りで把握するために作った。資料の流れは以下のとおり。

資料「TOPIX等の見直しの概要」の流れ

  1. 背景 — 第一段階の見直し完了(p.2) 2022年4月の市場区分再編を機にTOPIXの見直しが始まり、第一段階(市場区分との紐づけ廃止・ 政策保有株を浮動株から除外・流通株式時価総額100億円未満の段階的ウエイト低減)は2025年1月に完了。
  2. 第二段階 — 全市場対象・流動性重視へ(p.2-3) 連動資産約110兆円の連続性に配慮しつつ、対象をプライム・スタンダード・グロース全市場に拡大し、 流動性基準による年1回の定期入替を導入。広範網羅性と投資対象としての機能性を高める。
  3. 新ルール — 選定基準(p.3) 定期入替は年1回・10月最終営業日(基準日は8月最終営業日)。基準は下表の2指標:
    指標追加基準継続基準
    年間売買代金回転率0.2以上0.14以上
    浮動株時価総額の累積比率上位96%以内上位97%以内
    本アプリはこの継続基準の側を毎日再現している。
  4. 移行措置 — 段階的ウエイト低減(p.4) 初回入替(2026年10月)で継続されない銘柄は即時除外ではなく、四半期ごと8段階(87.5%→0%)で 2028年7月までウエイト低減。2027年10月に再評価があり、継続基準を満たせば低減停止。 第2回定期入替は2028年10月、以後毎年。
  5. 試算 — 約650銘柄が除外側に(p.6) 2026年3月末基準の試算では現行1,654銘柄 → 約1,050銘柄(スタンダード・グロースから約50銘柄を新規採用)。 つまり約650銘柄が移行措置(除外)側。累積97%圏内の最小浮動株時価総額は約360億円。 あわせて非選定銘柄の受け皿「TOPIX Next-tier」(約800銘柄)を新設(p.5, p.8)。
  6. → このアプリ 基準日(2026年8月末)の前に除外候補を知りたい。試算ボーダー約360億円+その後の相場上昇を踏まえ、 浮動株時価総額億円以下(+回転率0.14未満)を毎営業日21時に判定する仕組みを構築した (実測ボーダーはヘッダーに毎日表示)。選定結果の公式公表は2026年10月7日(10月第5営業日)、 入替実施は10月30日(10月最終営業日)。
